# 大小姐

> 开屏广告自动跳过工具 **开源自用版**。应用名是「大小姐」，工程与包名仍沿用 SkipAd
> （`com.noteatoranges.skipad`），改显示名不动包名——已装的旧版才能被正常覆盖。
> 零权限（连 INTERNET 都不申请）、零联网、所有识别本地完成。

## 它做什么

只做一件事：App 冷启动那几秒，把开屏广告上的「跳过」按掉。

识别分三层，越往下越保守：

1. **你自己建的规则**。广告在屏幕上时抓快照，点一下那个「跳过」，之后同类开屏就会自动点。
   不暴露控件树的应用（微信、货拉拉这类）用坐标规则，长按悬浮钮点一次屏幕位置让它记住。
2. **内置默认词**（默认开启）。「跳过 / 跳過 / Skip / スキップ / 건너뛰기」、倒计时句式，
   以及主流广告 SDK 的跳过控件命名。这一层负责你没建过规则的 App；觉得它死板可以在规则页整组关掉。
3. **右上角启发式**。广告既没文字也没可识别的控件命名时，按「右上角、小、可点击」找按钮。
   纯几何猜测，误判风险最高，所以只在前面两层都没命中的时候才试，一次开屏最多点一下。

规则不只扫主窗口，还会看同包的其他窗口。有些广告的「跳过」根本不在主窗口里
（比如 360 清理大师接的百度 mobads，主窗口几乎空白，按钮在另一个窗口的左下角），
只看主窗口会以为这个 App 没有广告。

前两层和第三层共用「启用内置默认词」这一个开关，关掉就只剩你自己建的规则。

只在**开屏窗口**里动手：App 从后台或桌面切回前台的头几秒。过了这个窗口，一条内置规则都不跑。

不联网、不申请 INTERNET、不读存储、不上传任何东西。识别全在本机做完。

## 怎么用

1. **安装**：下载 Release 里的 APK 直接装；系统问「未知来源」时允许一次。
2. **开无障碍**：打开大小姐 → 点「查看无障碍设置」→ 找到「大小姐 开屏跳过」并打开。
   Android 14 及以上如果是自己点 APK 装的，这个开关可能是灰的：先去 应用信息 → 右上角三点 →
   允许「受限设置」，再回来打开。
3. **保活**：设置 → 保活与后台 → 「去自启动管理」里允许大小姐自启动；电池优化选「不限制」。
   想让它掉线后自动爬回来（静默复活），电脑连上手机跑一次：
   ```
   adb shell pm grant com.noteatoranges.skipad android.permission.WRITE_SECURE_SETTINGS
   ```
4. **决定内置词要不要**：规则页「关键字」区块里的「启用内置默认词」默认开着。关掉之后只认你自己填的词
   和你建的规则——这不是「更准」，只是「更保守」，代价是没建过规则的 App 一律漏跳。
5. **建规则**：广告在屏幕上的时候，下拉通知栏点「抓取快照」（或在设置里打开「抓取悬浮窗」，
   点屏幕上的小圆钮）。回到 App → 跳过规则与快照 → 点开这份快照 → 点一下那个「跳过」按钮 →
   确认位置 → 保存。之后同类开屏就会自动点。
6. **出问题看哪里**：设置 → 数据与维护 → 引擎诊断。里面记着引擎最近做了什么 ——
   开屏窗口什么时候打开的、扫到了哪个控件、为什么没动手、哪一步抛了异常。

## 已知边界

- 内置默认词靠广告 SDK 的命名习惯。SDK 把关闭钮起成没有「关闭 / 跳过」含义的名字时，这一层认不出来，
  只能靠你自己建的规则补。
- 某个 App 的跳过按钮画在图片里（没有文字节点）时，前两层都用不上，落到右上角启发式。
  这时如果页面本身不是开屏，就有误点的可能；发现它在正常页面上乱动，就关掉「启用内置默认词」。
- 微信、货拉拉这类不暴露控件树的应用，只能靠「坐标规则」。
- 开屏页改版、按钮位置大改之后，旧规则会失配。目前没有自动告警，需要自己回头看引擎诊断或重抓快照。
- 只处理开屏广告，不处理应用内弹窗、信息流广告。
- 统计里的「已跳过 N 次」会排除「点完之后跳进广告落地页」的情况；但落地页上没有下载类按钮时，
  仍可能记成一次跳过。
